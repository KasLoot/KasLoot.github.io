RoboBrain

A closed-loop monitor that watches a robot work and reports, in real time, whether the task is on track, finished or failing, and why.

How it works

RoboBrain splits judgment into narrow questions. Each specialist answers one question about the current frame, and deterministic code decides what the answers mean.

Swipe sideways to see the whole diagram.

Why the answers are split up

Blue steps are model calls. Purple steps are deterministic code, so no single model answer can change the status on its own.
